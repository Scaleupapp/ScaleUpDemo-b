# TPO Portal W5 — Tier 3 (Report Export · Drive Pipeline · Cohort Analytics) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the platform with the three Tier-3 features: a one-click **placement report export** (CSV colleges submit/market with), a **drive pipeline** (interested → applied → shortlisted → offered, seeded by the student bookmarks already built), and **cohort analytics + at-risk students** (turn assessment data into intervention signals).

**Architecture:** Three additive backend pieces — a report CSV builder + routes, a `DriveApplication` model + pipeline routes (reads `DriveBookmark` to seed "interested"), and a read-only cohort analytics endpoint (composes `CohortRollup` + assessment sessions) — all institution-scoped + role-gated. Web wires a report-download button, a drive pipeline board, and an analytics/at-risk panel into the existing workspace.

**Tech Stack:** Backend — Node/Express/Mongoose; `node:test` + DI stubs. Web — Next.js using `app/org/_ui.tsx`.

## Global Constraints

- **Zero D2C impact.** Additive; institution-scoped (`institutionScope`); writes (pipeline) gated `institution_admin`/`tpo_head`/`tpo_coordinator`; reads any institution role. The `DriveBookmark` model (built earlier) is read-only here.
- **Backend tests:** `node --test <file>` (node v20 via nvm; else `~/.nvm/...`).
- **Deploy:** backend push `master`; web git-less Vercel.
- **Contracts:**
  - `GET /api/institution/cohorts/:cohortId/report.csv` → `text/csv` download (placement report).
  - `GET /api/institution/cohorts/:cohortId/drives/:driveId/applications` → `{ success, data: { stages: { interested, applied, shortlisted, offered, rejected }, applications: DriveApplication[] } }` (each stage = array of applications; "interested" includes bookmark-seeded students not yet an application).
  - `POST /api/institution/cohorts/:cohortId/drives/:driveId/applications` (add), `PATCH …/applications/:id` (move stage), `DELETE …/applications/:id`.
  - `GET /api/institution/cohorts/:cohortId/analytics` → `{ success, data: { competencies: [{name, avgScore, n}], atRisk: [{ studentName, rollNumber?, reason }] } }`.
  - `DriveApplication` JSON: `{ _id, driveId, studentName, rollNumber?, studentUserId?, stage, createdAt }`.

```js
async function buildReportRows(scope, cohortId, deps) {
  const Offer = (deps && deps.PlacementOffer) || require('../../models/PlacementOffer');
  const q = Offer.find({ ...scope, cohortId }).sort({ status: 1, createdAt: -1 });
  const offers = typeof q.lean === 'function' ? await q.lean() : await q;
  const header = ['Student','Roll No','Branch','Company','Role','CTC (LPA)','Type','Status','Offer date'];
  const rows = offers.map((o) => [
    o.studentName || '', o.rollNumber || '', o.branch || '', o.companyName || '', o.role || '',
    (typeof o.ctc === 'number' ? String(o.ctc) : ''), o.offerType || '', o.status || '',
    o.offerDate ? new Date(o.offerDate).toISOString().slice(0,10) : '',
  ]);
  return { header, rows };
}
```
Add to exports. Add the route to `outcomes.js`:
```js
function csvEscape(v) { const s = String(v ?? ''); return /[",\n]/.test(s) ? `"${s.replace(/"/g,'""')}"` : s; }
router.get('/cohorts/:cohortId/report.csv', institutionAuth, async (req, res) => {
```
