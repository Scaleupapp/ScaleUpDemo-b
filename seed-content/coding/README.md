This directory holds hand-authored seed bundles for the ScaleUp coding-practice content library. Each file is a JSON object that must conform to the ArtifactBundle schema defined in `src/coding/services/bundleSchema.js` — omit `content_hash`, `status`, and `generated_by` as the import script computes and sets those automatically. Run `npm run seed:coding` (or `node scripts/seed-coding-library.js --dry-run` to preview) to upsert all bundles into the `artifact_bundles` MongoDB collection; the operation is idempotent and uses `content_hash` as the deduplicate key.
